## Abstract

Frontier artificial intelligence models promise to accelerate scientific discovery by automating hypothesis formulation, experimental design, and computational code execution across complex biological domains. Yet adoption in the life sciences remains stalled. Researchers face a fundamental deficit of trust and computational scale. When investigators run autonomous agents on local machines, computations vanish into opaque terminal shells. Scripts remain unversioned. Intermediate files are overwritten without a record. Moreover, large biological datasets quickly overwhelm consumer hardware. We resolve this dilemma. Here we introduce an open agentic architecture that couples autonomous language models directly to public Galaxy cyberinfrastructure. This environment establishes computational transparency and provenance by construction. To direct long-horizon investigations, we develop Orbit, an opinionated research workbench that binds human intent, planning checkpoints, and remote cloud invocations into an interactive, living research notebook. Complementing this workbench, the Workflow Foundry compiles scientific literature into schema-validated workflows without manual scripting. Unprivileged User-Defined Tools allow agents to orchestrate containerized commands and heavy deep-learning models across national supercomputing allocations without administrative friction. By embedding provenance and reproducibility directly into the execution environment, our architecture transforms autonomous language models into disciplined, transparent, and verifiable scientific collaborators.

# Introduction

Across all scientific domains, LLM-powered agents formulate hypotheses, build analytical pipelines, execute code, and draft complete research manuscripts [1–6]. Recognizing these capabilities, academic and corporate laboratories have created specialized, domain-specific environments such as Co-Scientist to coordinate autonomous research [7]. Yet domain platforms cannot match the rapid development velocity, model optimizations, and tooling ecosystems powering general-purpose agent harnesses from the major artificial intelligence providers—Google, Anthropic, and OpenAI. At our own research institutions, we have watched numerous graduate students, postdocs, and PIs (even those who are AI-averse) adopt these agentic tools, become hooked, and stop analyzing data in any other way. This quickly makes general agent harnesses the primary working environment for modern computational research.

This rapidly widening use of agentic tools in science is equally thrilling and terrifying. The thrill comes from the speed and seemingly unlimited number of possibilities that suddenly became available to any researcher. The terror comes from a completely new set of scientific challenges that are not immediately apparent but will become severe as agentic science becomes the new norm. First, provenance tracking is largely absent. As unsupervised agents iterate, they generate ephemeral shell scripts, unversioned intermediate tables, and temporary scratch files. These ad-hoc artifacts vanish as soon as the session closes, and few have the proper version control skills and discipline to keep the full record. Scientific research requires that every analytical operation, tool version, and parameter choice be formalized into an immutable, shareable record so that colleagues can inspect, verify, and reproduce the complete computational trajectory. Second, autonomous agents require community-curated skills and standardized, high-quality bioinformatics tools. Rather than improvising custom scripts from unvetted online snippets, agents must make analytical decisions guided by verified computational protocols and validated tool specifications that function across different agent harnesses. Third, the agentic revolution does not change the need for infrastructure access. While modern laptops handle exploratory scripting effectively, production biological workflows—such as large-scale genome assembly, analyses of large multi-sample datasets, or deep learning inference—demand high-performance computing clusters with hundreds of processor cores, massive memory allocations, and dedicated hardware accelerators. Installing autonomous agent harnesses directly onto shared institutional supercomputers violates facility security policies and remains administratively unsustainable.

For over twenty years, the Galaxy platform has provided open, reproducible cyberinfrastructure to life scientists worldwide [8]. It now serves as an ideal agentic plane to address these challenges. First, it provides a universal compute abstraction that schedules complex, containerized analytical workloads across heterogeneous institutional clusters, national supercomputing allocations, and commercial clouds without requiring interactive login credentials, private keys, or command-line administrative access. Second, Galaxy's web interface and history system serve as an ideal artifact display mechanism. Every analytical step, parameter choice, and intermediate dataset is recorded within an immutable directed acyclic graph that investigators and their collaborators can inspect, audit, visualize, and re-execute with a single click. Third, the platform supplies the definitive scientific knowledge base. The Intergalactic Utilities Commission maintains thousands of vetted, containerized tool wrappers, the Intergalactic Workflow Commission curates standardized analytical pipelines, and the Galaxy Training Network provides hundreds of peer-reviewed, step-by-step procedural tutorials. Finally, the Workflow Foundry translates external bioinformatics knowledge—including Nextflow pipelines and published methods—into structured agentic skills that guide autonomous execution across Galaxy cyberinfrastructure [9]. Galaxy grounds autonomous language models in transparent, reproducible, and vendor-agnostic scientific infrastructure.

Here we demonstrate the utility of our platform across 44 empirical evaluations, reproducing 43 published cohorts across 38 studies and conducting a novel large-scale analysis of antigenic variation in malaria. In spatial transcriptomics, an agent reproduces published conformal uncertainty predictions to numerical precision, then scales the workflow across an expanded reference cohort. In structural phylogenomics, the agent builds unprivileged User-Defined Tools to execute deep-learning protein language models on remote GPU clusters. This structural clustering collapses 146 fragmented *Plasmodium vivax* antigen subfamilies into 73 shared classes. In genomic epidemiology, the platform automates emergence dating across 42 published pathogen epidemics. Tree-free manifold geometry matches compute-intensive Bayesian benchmarks in seconds per study. Across all three investigations, every analytical step, containerized tool, and intermediate dataset is documented as an immutable history on public cyberinfrastructure.

# Results

## Advanced models propose vastly different analysis plans ...

Today many biological researchers discover how seemingly easy it is to conduct data analysis with agents. Suppose a student is given a task of analyzing RNA-seq data by an advisor. The student is adventurous enough to try to use one of the widely advertised agents. The student uploads data, explains to the agent the experimental design, and asks it to propose an analysis plan (Note that planning is not a widely adopted discipline in biomedical research and that appropriate use of agents requires significant changes to the present curriculum.). How does the student know that the proposed plan is good? How would the student choose among possibilities proposed by an agent? To illustrate this problem we asked 30 agents (10 for each of Anthropic, OpenAI, and Google, respectively) to propose reanalysis plans for a paper (because we know what the expected outcome should be) describing a published transcriptomic study (PMC12804731) [10]. The agents generated 18 proposed workflows (Figure [fig:agent_trajectories]). While differences like workflow engines were purely operational, eleven of these plans would produce different scientific outcomes if executed. They made conflicting biological choices across reference genomes, read strandedness, and statistical sample pooling. These choices would also result in dramatic changes in resource requirements, as shown in Supplementary Table [tab:agent_resources]. 

## ... and leave a dusty trail of intermediats.

To test how these proposed workflows perform in practice, we tasked one representative agent from each model family with executing its analysis on dedicated local hardware (bold highlighted ribbons in Figure [fig:agent_trajectories]). All three recovered the expected biological signals (Figure [fig:agent_execution]). Each confirmed glucose repression of the enterotoxin subunit *nheB*, induction of enterotoxin *entFM*, and genomic absence of the *hbl* operon. Yet beneath this biological concordance lay total computational divergence. The three platforms selected incompatible reference assemblies, different aligners, and conflicting statistical models. Their resource footprints varied by orders of magnitude (Supplementary Table [tab:agent_resources]). To bridge missing infrastructure, the agents generated twenty-six distinct custom scripts totaling over 1,200 lines of unversioned code (Supplementary Table [tab:agent_scripts]). Their engineering strategies differed fundamentally. Gemini executed three monolithic shell and R scripts with hardcoded local paths. Claude built nine wrapper scripts to drive containerized Nextflow pipelines. Codex engineered fourteen modular scripts to enforce memory limits and track pruned files. None of these custom scripts were portable or auditable beyond the machines where they ran. Each agent left behind an ephemeral debris field of temporary glue code, isolated environments, and unversioned logs. Autonomous agents can recover biological signals. They cannot produce shareable, permanent scientific records without a common cyberinfrastructure plane.

## Agentic science on public infrastructure: The Galactic plane

The benchmarking results above highlight the core problems of unassisted agentic science: conflicting and inconsistent analytical trajectories, unversioned glue code, and the limits of local hardware (Figures [fig:agent_trajectories] and [fig:agent_execution]). To produce trustworthy and verifiable results, agents need field-specific guidance and shared infrastructure (Figure [fig:architecture]). Domain skills and the Model Context Protocol (MCP) establish essential guardrails (Figure [fig:architecture], Panel 2) [11, 12] by following community-curated analysis pathways and preferring validated tool invocations to generating transient code. But agents also need a uniform, shared execution engine for three reasons. First, compute scale and access: a modern laptop can process large amounts of data, but tools like STAR [13] do not scale across cohorts even on modern machines. Making genetic science accessible also requires accounting for researchers who lack powerful local hardware. Second, tools impossible to run locally: methods like, for example, AlphaGenome [14], Logan [15], or LexicMap [16] require massive indices or large models that no workstation can host. Third, and this is critical: reproducibility. One can argue that agentic outputs are reproducible because models can summarize their own actions. In practice, this requires strict discipline---such as running every analysis from versioned Git repositories---that few biologists maintain. A viable system must track computational provenance automatically without relying on user habits. Agents can prototype locally, but the final outcome must be pushed and executed on the cloud, detaching the analysis from irreproducible local silos. Pushing computation to public infrastructure guarantees provenance by default (Figure [fig:architecture], bottom loop). Every input, tool version, custom script, metadata, and intermediate dataset becomes part of a permanent record that can be examined and shared.

The Galaxy ecosystem provides this execution engine (Figure [fig:architecture], Panel 3) [8]. Backed by twenty years of tool execution expertise, its vast library of tutorials and workflows supplies procedural skills for diverse analyses. Galaxy schedules any workload complexity---embarrassingly parallel tasks, large shared-memory assemblies, and GPU models---across public cyberinfrastructure. Researchers never have to negotiate agentic shell or head-node access with high-performance computing administrators---the execution fabric is already there.

Our vision for agentic science unites any agent runtime (Figure [fig:architecture], Panel 1), community-curated skills---drawn from tutorials, workflows, and purpose-built skills---and public infrastructure. Agents reuse existing tools first. When a missing step requires an ad-hoc script, such as a converter for an unconventional format, the agent writes and registers a tool directly into the workflow, where it can later mature into permanent software. Across thousands of users and hundreds of thousands of analyses, recurring patterns surface to form a community cloud of such ad-hoc tools.

## Reproducing a paper using a generic agent on the galactic plane

To test this architecture in practice, we tasked an autonomous agent with reproducing the *Bacillus cereus* RNA-seq benchmark (PRJEB86181) from the earlier section, connecting it directly to UseGalaxy.org through the Galaxy Model Context Protocol (MCP) server [10, 11]. Unlike unconstrained local agents that generated dozens of unversioned scripts or stalled from disk exhaustion, this execution ran entirely on remote supercomputing allocations (Figure [fig:bacillus_replication]). As we communicated with the agent and inspected its proposed workflows in Galaxy, we noticed that it initially selected HISAT2, a eukaryotic spliced aligner. Because *Bacillus cereus* is an intronless bacterium, spliced alignment adds computational overhead without biological benefit, so we directed the agent to switch to Kallisto pseudoalignment against curated coding sequences [17]. This switch accelerated processing by more than fifteenfold while eliminating spurious bacterial splice junctions. We spotted this mismatch because we knew what to look for, whereas a less experienced user might not. The broader strategy here is that as more researchers use this platform, our community skills improve alongside the underlying models---encoding the knowledge that bacterial RNA-seq requires different tools than eukaryotic RNA-seq.

Building a working pipeline also requires catching incompatibilities between tools and quirks in reference annotations. When assembling the workflow in Galaxy, the agent initially tried to pass Kallisto's transcript-level abundance tables directly into DESeq2, which expects gene-level count matrices (Figure [fig:bacillus_replication]A). Galaxy's workflow editor flagged this incompatible connection before any jobs were launched. The agent fixed the workflow by adding a lookup table that maps bacterial coding sequences to their parent gene loci, allowing DESeq2 to aggregate transcript abundances into gene-level estimates (Figure [fig:bacillus_replication]B, see Methods). The agent also caught an annotation issue in the *Bacillus cereus* reference genome. Bacterial annotations often contain programmed ribosomal frameshifts or disrupted open reading frames, which split a single gene into multiple coding sequence entries with duplicate identifiers. By testing the workflow on a small subset of reads first, the agent detected and merged these split entries before running all five libraries (Figure [fig:bacillus_replication]C).

The resulting analysis reproduced the published biological findings exactly (Figure [fig:bacillus_replication]D). Under glucose supplementation, the non-hemolytic enterotoxin operon showed marked repression: primary lytic subunit *nheB* decreased 5.05-fold ($\log_2\text{FC} = -2.335$, $p_{\text{adj}} = 2.99 \times 10^{-3}$), which reproduces the published significance threshold ($p_{\text{adj}} < 0.01$). Subunit *nheA* decreased 2.80-fold ($\log_2\text{FC} = -1.484$, $p = 0.0274$), whereas regulatory subunit *nheC* remained unaffected ($\log_2\text{FC} = -0.158$, $p = 0.843$). Conversely, cell-wall enterotoxin *entFM* was induced 2.71-fold ($\log_2\text{FC} = +1.432$, $p = 0.0158$). Across all 5,472 bacterial genes, Kallisto pseudoalignment and HISAT2 spliced alignment showed near-perfect agreement (Pearson $r = 0.9622$). Every dataset, tool parameter, and analytical step remains permanently accessible on UseGalaxy.org as a published workflow, a public history, and an interactive research notebook (Figure [fig:bacillus_replication]C, see Methods). The agent left behind an executable scientific asset instead of ephemeral glue code.

## An opinionated agent

Skills and MCP guide generic agents well, as the *Bacillus cereus* replication above shows. For new users in particular—especially biologists who have never run command-line agents from the shell—there is a clear need for a friendly, lightweight desktop agent with additional agent harness logic. That agent harness logic matters because it gives tighter control over skills and MCP endpoints, adding extra guardrails to guide the analysis. We therefore developed Orbit, a lightweight desktop application built on top of Pi.dev (Figure [fig:architecture], Panel 1).

One of Orbit's advantages is that it provides Galaxy-specific features, including direct research notebook export, live job tracking, and unprivileged User-Defined Tool registration [18]. It also supports multiple language models: commercial models via API keys or subscriptions, public models via API keys, and local models running directly on the machine where Orbit runs. Thus, we support two modes of agentic use on the Galactic plane (Figure [fig:architecture], Panel 1): researchers can connect any generic agent via community skills and the Galaxy MCP server, or they can run our opinionated agent, Orbit, which layers Galaxy-specific agent harness logic and multi-model flexibility on top of those same interfaces. Below, we evaluate both modes across a wide range of biological applications—spanning fungal, parasitic, and vector transcriptomics, ChIP-seq, ATAC-seq, single-cell atlases, spatial transcriptomics, structure-aware phylogenomics, and pathogen emergence dating—producing fully reproducible, provenance-rich records for every analysis.

## Cross-Model Reproducibility in Orbit: *Candida auris* Adhesin Transcriptomics

Because Orbit supports commercial, public API, and open-weight language models, we first asked whether different models driving the same agent harness on the Galactic plane converge on identical scientific conclusions. We tasked eight frontier model configurations in Orbit—Claude Opus 4.7, Claude Sonnet 4.6, Claude Haiku 4.5, OpenAI GPT-5.5 (two independent runs), Gemini 2.5 Pro, Gemini 3.5 Flash, and DeepSeek—with independently reanalyzing bulk RNA-seq data from Santana et al. [33] (BioProject PRJNA904261). That study identified the *Candida auris* adhesin gene *SCF1* as a key determinant of surface colonization and virulence across two contrasts (`tnSWI1` vs. `AR0382` and `AR0387` vs. `AR0382`). Reproducing this result on the current B8441 v3 reference assembly (`GCA_002759435.3`) poses a subtle biological trap: between the v2 assembly used in the paper and the current v3 reference, 6-digit locus tags were silently renumbered. A naive string rule that strips a leading zero maps the published *SCF1* identifier (`B9J08_001458`) to an unrelated v3 gene (`B9J08_01458`), yielding a false-negative result ($\log_2\text{FC} = -0.036$, $p_{\text{adj}} = 0.83$). Resolving the true ortholog requires protein-level reciprocal best-hit matching via DIAMOND, which maps *SCF1* to `B9J08_03708`.

Six of the eight Orbit runs completed the full pipeline on UseGalaxy.org and reproduced the severe downregulation of *SCF1* across both contrasts ($\log_2\text{FC} \approx -6.82$ and $-7.35$, $p_{\text{adj}} \approx 0$, Figure [fig:scf1_attempts]A), while two runs (the first GPT-5.5 attempt and Claude Haiku 4.5) aborted during initial history preparation. Runs that invoked the unmodified Intergalactic Workflow Commission paired-end RNA-seq and differential expression workflows (`rnaseq-pe` and `rnaseq-de`) produced bit-identical expression estimates to twelve significant figures across different model providers (Claude Sonnet 4.6 and OpenAI GPT-5.5). Because UseGalaxy.org provided all compute and storage at zero cost, language model API spend was directly comparable across runs and spanned a 47-fold range—from \$2.82 for DeepSeek and \$16.22–\$24.87 for mid-tier models to \$131.83 for Claude Opus 4.7 (Figure [fig:scf1_attempts]B). Higher model spend bought fuller autonomous polish and fewer human nudges, not different scientific answers: once grounded in curated Galaxy workflows and protein orthology checks, six distinct models converged on the exact same biological result, with every run preserved in its own public Galaxy history (Supplementary Table [tab:brc_artifacts]).

## Compiling a 30-Sample Fungal Transcriptomic Time-Course with Workflow Foundry

To test how external literature procedures compile into verifiable workflows without interactive desktop steering, we used Workflow Foundry [9] and BRC-Analytics to reconstruct the 30-sample RNA-seq study of Hokken et al. [34] on itraconazole-induced transcriptional plasticity in *Aspergillus fumigatus* (BioProject PRJNA482512). The dataset spans three clinical isolates sampled across five exposure timepoints (0, 30, 60, 120, and 240 minutes) in duplicate. Starting from the publication text, BRC-Analytics resolved the *A. fumigatus* Af293 reference genome (Ensembl Fungi ASM265v1) and all 30 sequencing runs, while Workflow Foundry compiled a 60-step Galaxy workflow (`b3638784a5d2aa43`) combining fastp trimming, STAR alignment with simultaneous gene counting, DESeq2 modeling, functional enrichment, cross-study set comparisons, and visualization. Across all 30 libraries, the mean unique STAR alignment rate reached 86.88%, matching the 86.5% reported in the paper. Inspecting the ratio between STAR's forward and reverse strand-specific count columns across ten representative libraries yielded values between 0.979 and 1.007, empirically verifying that the libraries were unstranded before downstream modeling.

Reproducing the published differential expression counts uncovered an essential statistical design detail. Fitting four separate 12-sample pairwise DESeq2 models matched the published $\log_2$ fold-change values almost perfectly ($r \ge 0.999$). However, those pairwise fits fell short of the published differentially expressed gene (DEG) counts by 31% at 120 minutes and 39% at 240 minutes, recovering only 82 of the 186 genes reported across all four timepoints. Inspecting the published supplementary table revealed why: every gene carried a single identical `baseMean` value across all four contrasts, proving that the authors fitted one pooled 30-sample five-level factor model rather than four pairwise models. Twelve-sample fits inflated standard errors by 18–26%, preventing attenuated late-timepoint responses from clearing the significance threshold. Switching the workflow to a single pooled 30-sample DESeq2 fit reproduced the published standard errors to four decimal places and matched the published DEG counts within 0.3–0.9% at every timepoint ($\log_2\text{FC}$ Pearson $r = 0.9996\text{–}0.9999$, Figure [fig:brc_reproductions]A). Specifically, the pooled model identified 3,922 vs. 3,955 DEGs at 30 minutes, 3,393 vs. 3,430 at 60 minutes, 1,191 vs. 1,207 at 120 minutes, and 1,098 vs. 1,101 at 240 minutes. It also recovered 185 consistently differentially expressed genes against the published 186, with 181 shared between both sets. Where three web utilities used in the 2018 study (AspGD GO Term Finder, BioVenn, and REVIGO) had since been decommissioned, the agent built three documented User-Defined Tools to perform hypergeometric Gene Ontology enrichment, two-way set overlaps across `AFUA_` and `Afu` identifier namespaces, and Jaccard ancestor-set redundancy reduction. These tools reproduced both the temporal enrichment inversion (135 upregulated vs. 2 downregulated terms at 30 minutes, reversing to 0 upregulated vs. 136 downregulated terms at 240 minutes) and the 61-gene drug-efflux transporter cluster (*mdr1*, *mdr4*, *abcA*, *abcC*, and *mfs56*) within a single published Galaxy history (Supplementary Table [tab:brc_artifacts]).

## Reanalyzing the SrbA Hypoxia Regulon Across Historical and Modern Fungal Assemblies

We next used Orbit, BRC-Analytics, and UseGalaxy.org to reanalyze the ChIP-seq and transcriptome study of Chung et al. [35], which defined the direct target regulon of the sterol regulatory element-binding protein SrbA during hypoxia in *Aspergillus fumigatus*. Reproducing ten-year-old ChIP-seq studies often blurs the line between genuine signal recovery and post-hoc threshold tuning. To prevent parameter fishing, the agent locked a pre-registered reproducibility plan before execution. Peaks called on the historical A1163 assembly used by the original authors were evaluated at a fixed 2 kb promoter, gene-body, and transcription start site (TSS) assignment window, accompanied by a hard-coded sensitivity ladder (2, 3, 5, 7, and 10 kb) to test whether unrecovered targets reflected absent ChIP-seq signal or annotation coordinate drift. Eight custom User-Defined Tools were created and embedded inline within four published Galaxy workflows (`ff4cd12fc5e65a6c`, `2203902a6116019b`, `86d8cc638f881fe8`, and `62a14d1fb200c320`) so that third-party researchers can re-execute the complete post-processing chain without account-permission restrictions.

At the pre-specified 2 kb assignment window on the historical A1163 assembly, the Galaxy reanalysis recovered 89 of the 97 non-repetitive direct SrbA target genes reported in Table S2 of Chung et al. (91.8%, Figure [fig:brc_reproductions]B), including all 11 canonical virulence, ergosterol biosynthesis, and iron acquisition markers (*cyp51A*, *erg1*, *erg3*, *erg25*, *srbB*, *sit1*, *niaD*, and *niiA*). ## Reconstructing Chromatin Accessibility Dynamics Across Malaria Blood-Stage Development

Multi-omic time-course integrations across non-model parasites test whether an agentic workbench can diagnose subtle algorithmic discrepancies across multi-step pipelines. Using Orbit on UseGalaxy.org, we reproduced the ATAC-seq and RNA-seq study of Toenhake et al. [36], which mapped chromatin accessibility and target gene expression across eight intraerythrocytic developmental cycle (IDC) timepoints in *Plasmodium falciparum* 3D7 (GEO GSE104075). We structured the reproduction into two stages so that downstream regulatory assignment could be evaluated independently of upstream peak calling. First, we supplied the authors' 4,035 deposited accessible regions directly to our Galaxy downstream workflow, which normalized PlasmoDB Release 26 and RefSeq chromosome accessions, quantified accessibility across all eight fragment-filtered ATAC-seq alignments via `bedtools MultiCovBed`, excluded coding summits, and correlated accessibility against time-matched RNA-seq profiles. On the deposited peaks, the Galaxy pipeline recovered 1,999 to 2,035 positively correlated accessible-region–gene pairs (Pearson $r \ge 0.6$), matching 94.4–96.1% of the 2,118 pairs reported by Toenhake et al.

When we initially attempted to rebuild the peak universe from raw reads, however, the pipeline produced 4,321 merged regions that covered 79–92% of the nuclear genome and yielded only 574 correlated gene pairs. Because every intermediate dataset and parameter sweep was preserved in the Galaxy history (`bbd44e69cb8906b51a8fc57163ace281`), inspecting the provenance record revealed the exact cause: an early smoke-test placeholder tool (`pf-toenhake-qpois-smoke`) had never been replaced. Compared against the paper's stated MACS2 chain (`macs2 pileup` with read extension $\rightarrow$ `bdgcmp -m qpois` against a genomic DNA control pileup with a 0.1 pseudocount $\rightarrow$ `bdgpeakcall -c 3 -l 100 -g 150`), the placeholder omitted read extension, computed raw $p$-values instead of $q$-values, and lacked the 0.1 control pseudocount. Without that pseudocount, every base where the genomic DNA control had zero cuts (~5% of the genome, or one position every ~20 bp) saturated at the tool's maximum score cap of 300, which the 150 bp merge step chained into genome-wide blankets. Replacing the placeholder with Galaxy's standard MACS2 2.2.9.1 implementation and scaling the genomic DNA control per million reads (rather than per million fragments) passed the paper's $t_{40}$ AP2-I transcription factor checkpoint (2,605 peaks with 164/167 AP2-I overlaps vs. 2,771 peaks and 165/169 reported) and rebuilt 3,903 merged accessible regions against the published 4,035 (97%, Figure [fig:brc_reproductions]C). By coordinate, the rebuilt peak universe recovered 91.3% of the authors' deposited regions at 96.4% precision, retained 3,649 intergenic regulatory regions (vs. 3,755 published, 97%), and carried through to 1,918 correlated peak–gene pairs ($r \ge 0.6$, 91% of the published 2,118, Supplementary Table [tab:brc_artifacts]).

## Disentangling Biological Signal from Undocumented Post-Processing in Mosquito ATAC-seq

A central advantage of executing agentic reanalyses on public infrastructure is the ability to separate biological reproducibility from undocumented post-processing rules in published tables. We used Orbit and UseGalaxy.org to reanalyze the study of Ruiz et al. [37], which profiled chromatin accessibility changes in *Anopheles gambiae* midguts and salivary glands across two independent *Plasmodium falciparum* infections (GEO GSE152924, runs `SRR12064732`–`SRR12064735`). Following the published methods, the agent aligned reads with Bowtie2, filtered for $\text{MAPQ} \ge 10$, removed PCR duplicates, and built a custom User-Defined Tool (`ruiz_tn5_fragment_extractor`) to apply $+4/-5$ bp Tn5 offset shifts and isolate sub-nucleosomal fragments ($< 130$ bp) before calling peaks with the exact historical caller version cited by the authors (MACS2 2.1.2). We then separated the evaluation into two questions: whether the genomic coordinates reported by Ruiz et al. are recoverable from the raw reads, and whether the paper's stated cross-infection overlap rule reproduces its headline region counts.

On the first question, the biology reproduced cleanly with zero free parameters: measured at the paper's stated 51% reciprocal-overlap criterion against the authors' deposited region table, independent MACS2 2.1.2 peak calls recovered 92.4% and 93.2% of reported midgut regions and 90.7% and 93.2% of reported salivary-gland regions across the four libraries. On the second question, however, applying the stated 51% reciprocal-overlap rule between the two reconstructed infection replicates yielded only 9,448 midgut and 19,502 salivary-gland regions against the published 43,010 and 68,576—a fourfold shortfall that persisted even under relaxed peak-calling stringency (21,841 and 31,513 regions) or without duplicate removal (21,775 and 30,844 regions). Inspecting the structure of the authors' supplementary table revealed that each replicate peak was retained as an unmerged row. A systematic grid search showed that a near-containment rule (`either_frac` $= 0.851$, where either peak covers at least 85.1% of the other) reproduced the published totals (44,780 midgut and 67,594 salivary-gland regions) along with downstream assigned genes, promoters, and candidate enhancers within 0.4–4.6% (Figure [fig:brc_reproductions]D). Rather than reporting this fitted threshold as an independent confirmation, the agent executed a pre-registered cross-tissue transfer test (`ruiz_either_frac_crossfit`) showing that the single-tissue optima diverged (`0.884` in midgut vs. `0.821` in salivary glands). Archiving both the unfitted coordinate recovery and the fitted post-processing exploration across three public Galaxy histories and two published workflows (`32f57ede003070c3` and `6c3ed747eba652a6`, Supplementary Table [tab:brc_artifacts]) preserved a transparent audit trail distinguishing verifiable chromatin biology from an unstated counting step.

## Rebuilding a Mosquito Midgut Single-Cell Atlas on Public Infrastructure

To evaluate single-cell transcriptomic workflows on non-model disease vectors, we paired BRC-Analytics with UseGalaxy.org to reanalyze the adult female *Aedes aegypti* midgut single-cell RNA-seq atlas of Wang et al. ## Heavy-Weight Model Orchestration and Structure-Aware Phylogenomics

The *Plasmodium* interspersed repeat (*pir*) multigene family, termed *vir* in *Plasmodium vivax*, encodes exported surface adhesins that mediate antigenic variation and host immune evasion [21]. Initial sequence-based classifications based on the incomplete, short-read Salvador-I reference defined ten to twelve subfamilies, designated VIR-A through VIR-L [22, 23]. Subsequent long-read assemblies expanded this repertoire fourfold, identifying over 1,000 *vir* genes per genome across isolates from Indonesia (PvP01) [24] and Peru (PvPAM) [25]. Rapid sequence diversification drops amino acid identity into the twilight zone, reaching a median of only 32% across homologs. Standard sequence alignment fails at these distances. Markov clustering fractures the repertoire into 146 artificial subfamilies. Because over 600 South American VIR proteins lacked one-to-one sequence orthologs in Southeast Asian genomes, earlier studies hypothesized rapid, lineage-specific continental radiation. Yet crystallographic structures show that divergent PIR ectodomains share a conserved four-helix bundle fold despite extreme loop hyper-variability (PDB 6ZYV) [26]. We asked whether an autonomous agent could orchestrate structure-aware phylogenomics on public cyberinfrastructure across long-read assemblies from Indonesia, Thailand, and Peru to test whether structural clustering unifies this fragmented repertoire and whether antigenic diversity reflects recent continental radiation or ancient global panmixia.

The investigation proceeded autonomously on UseGalaxy.org. The agent screened candidate loci against Pfam PF05795 across the three continental genomes using Galaxy's HMMER tool to identify VIR-like genes. Because standard sequence tools could neither embed nor align structural alphabets, the agent built and registered ten unprivileged User-Defined Tools. To predict three-dimensional structural alphabets (3Di) directly from sequences without expensive coordinate modeling, the agent packaged the 4.4-gigabyte ProstT5 transformer model with Foldseek. The agent specified GPU resource allocations directly within the tool schema to route execution to an NVIDIA A100 node on ACCESS-CI cyberinfrastructure. When standard FoldMason containers failed from missing compilation flags, the agent diagnosed execution logs and built a functional container image (`quay.io/nekrut/foldmason-prostt5:4.dd3c235-cpu`). The finalized workflow linked six-frame pseudogene translation, 3Di structural clustering, lockstep amino acid and structural multiple alignment, synteny evaluation against 5,120 housekeeping genes, and partitioned maximum-likelihood phylogenetics.

Structural clustering halved repertoire complexity (Fig. [fig:vir_reconstruction]a). Foldseek collapsed 2,592 VIR proteins from 146 sequence subfamilies into 73 structural classes. The dominant structural superfamily, FS_001, absorbed 1,197 proteins (46% of the total repertoire) and merged 89 sequence subfamilies that previous methods treated as unrelated lineages. Structural classes proved universally shared across geography. Over 97.3% of VIR proteins resided in clusters containing representatives from Indonesia, Thailand, and Peru. Lineage-unique clusters accounted for only 2% of sequences. Maximum-likelihood structural phylogenetics of 338 FS_001 representatives demonstrated complete geographic interleaving across continents (Fig. [fig:vir_reconstruction]b). Tip-label parsimony tests treating genome of origin as a discrete character confirmed that the observed geographic distribution was indistinguishable from random permutation ($p = 0.55$). Diversification predated continental separation. Chromosomal mapping revealed that 64.5% of VIR loci reside within the outer 10% of chromosomal termini. This subtelomeric clustering creates an evolutionary engine for ectopic exchange that scrambles flanking gene order while preserving the structural core. Sequence alignment alone misidentifies orthologs. Out of 194 reciprocal best-hit pairs between Thailand and Peru within FS_001, only eleven maintained flanking microsynteny against the housekeeping backbone. An automated verification suite validated 77 independent quantitative claims against raw outputs, achieving complete concordance (77/77 PASS).

## Emergence Dating Across 42 High-Priority Pathogens

Accurately estimating pathogen emergence dates and evolutionary rates is central to genomic epidemiology. Canonical divergence time estimation relies on Bayesian Markov chain Monte Carlo frameworks implemented in BEAST [27]. These models explore genealogical trees, branch lengths, and demographic priors simultaneously. Computational scaling breaks down on large cohorts. Joint Bayesian inference across thousands of viral genomes demands weeks of high-performance cluster runtime to achieve MCMC convergence. To eliminate this computational bottleneck, we recently developed HyphAeon, an analytical framework that extracts evolutionary velocities directly from sequence distance geometry and continuous manifold embeddings without reconstructing phylogenetic trees [28]. Here, we asked whether an autonomous agent could orchestrate the systematic re-analysis of emergence dates across 42 published high-priority pathogen cohorts on Galaxy cyberinfrastructure to determine whether tree-free manifold dating achieves numerical concordance with established Bayesian benchmarks across diverse genomic scales and evolutionary regimes.

The investigation proceeded autonomously on UseGalaxy.org. The agent compiled 42 published reference cohorts spanning diverse viral and bacterial epidemics, including Ebola, SARS-CoV-2, Zika, Dengue, Chikungunya, Mpox, and *Yersinia pestis*. Original author XML files were archived to guarantee byte-level provenance. The agent built and registered two unprivileged User-Defined Tools. The first tool, `chronaeon_batch_preparator`, validated XML syntax, extracted aligned nucleotide matrices, and structured inputs into synchronized 42-element Galaxy dataset collections. The second tool, `chronaeon_cohort_analysis`, executed tree-free Date regression, non-linear spline clock fitting, manifold clustering, and leave-one-out cross-validation. Galaxy mapped all 42 cohort jobs concurrently across distributed high-performance nodes.

All 42 reference cohorts completed successfully on UseGalaxy.org with a median execution time of 3.41 seconds per study (Fig. [fig:chronaeon_42cohorts]). Rather than relying on commodity workstations, the agent dispatched these manifold computations to dedicated high-performance nodes on ACCESS-CI cyberinfrastructure equipped with NVIDIA A100 GPUs (80GB VRAM) and AMD EPYC processors. Published Bayesian MCMC runs required tens to hundreds of CPU-hours on identical alignments. In the 2014 Sierra Leone Ebola outbreak (196 taxa), tree-free dating estimated a root date of 2014.23 (95% CI: [2014.17, 2014.27]) with a cross-validation mean error of 26.4 days, matching the published BEAST root of 2014.20 ([2014.10, 2014.30]) [29]. For the 2014–2016 West African Makona lineage (1,610 taxa), the inferred root of 2013.81 ([2013.74, 2013.86]) agreed closely with published BEAST estimates (2013.98, [2013.79, 2014.15]) [30]. Tree-free dating also resolved the SARS-CoV-2 Gamma emergence at 2020.71 (BEAST: 2020.87, error: 17.0 days).

Comparative outcomes organized across a four-part analytical taxonomy. Category I comprised unimodal concordance (19 cohorts, 45.2%), where active longitudinal sampling under stable substitution rates yielded direct convergence with BEAST credible intervals. Category II captured genealogical scope mismatches (9 cohorts, 21.4%). In these datasets, unpartitioned distance regression evaluated the crown of sampled sequences, whereas published studies conditioned on tree priors to date deep roots or introductions. Applying AutoClock normalized Laplacian spectral bisection ($K^*$) decoupled localized transmission crowns without taxonomic labels. Spectral deconvolution recovered the published 1960 mode in Dengue-3 within 1.6 years (1961.62 vs 1960.0) [31], matched the 2007 European introduction in African swine fever (2006.53 vs 2006.15), and isolated the acute 2005 island wave in Chikungunya La R{é}union (2005.10 vs 2004.80). Reconciling genealogical scope elevated benchmark concordance to 59.5% (25 of 42 cohorts), reaching $R = 0.86$ ($R^2 = 0.74$) across modern surveillance datasets. Category III captured regularization differences (8 cohorts, 19.0%). In datasets with narrow temporal depth or mutational sparsity, tree priors perform heavy shrinkage in Bayesian MCMC, manufacturing narrow intervals. Distance geometry computes exact finite-sample bounds via Fieller's theorem [32]. When temporal signal is indistinguishable from noise ($g \ge 1.0$), Fieller intervals expand to infinity, alerting researchers that data lack longitudinal signal. Category IV captured lineage heterotachy and rate mixtures (6 cohorts, 14.3%), where AutoClock separated asynchronous sub-epidemics.

# Discussion

The integration of autonomous artificial intelligence into empirical science represents a critical turning point. If autonomous agents continue to operate as disembodied conversationalists inside private local environments, computational science will fragment into an unobservable collection of irreproducible, post-verifiable claims. By providing artificial intelligence with an open, distributed computational body, our architecture establishes a new paradigm: verifiable agentic science governed by provenance by construction.

Scientific progress relies on the ability of independent researchers to inspect, challenge, and replicate computational findings. In conventional agent workflows, reproducibility depends entirely on post-hoc human discipline—an assumption that consistently fails in practice. Domain researchers interacting with conversational agents rarely record intermediate commands, pin operating system dependencies, or preserve raw data transformations.

Our architecture transfers the burden of reproducibility from human discipline to computational infrastructure. By executing analyses across Galaxy cyberinfrastructure, every analytical step is recorded upon an immutable directed acyclic graph. Tool versions, container digests, parameter values, and intermediate datasets are sealed in a permanent provenance ledger. This record is not an optional export—it is the physical mechanism through which compute occurs. Consequently, scientific claims generated through this framework carry complete execution lineage, ensuring that autonomous discoveries remain verifiable by the global scientific community.

The computational demands of frontier artificial intelligence threaten to centralize scientific discovery within well-funded commercial institutions. When automated research requires private compute clusters and proprietary cloud platforms, independent academic investigators are systematically excluded from high-throughput discovery.

We demonstrate that public, federally supported cyberinfrastructure can serve as the foundational execution surface for modern artificial intelligence. By pairing open foundation models and universal protocols with the Galaxy platform, we democratize autonomous science. A researcher at an under-resourced institution, equipped only with a standard laptop, can direct autonomous agents that orchestrate distributed supercomputing allocations, query petabyte-scale reference archives, and execute high-throughput pipelines across national high-performance clusters. Preserving the public scientific commons in the era of artificial intelligence is not merely an ethical priority—it is an infrastructural necessity for ensuring universal participation in scientific discovery.

Looking forward, coupling autonomous reasoning to open cyberinfrastructure establishes the foundation for a collaborative, planetary-scale scientific network. In this ecosystem, published workflows, curated reference databases, and execution engines communicate through standardized machine-readable protocols. Autonomous agents will not operate as isolated local assistants, but as distributed co-investigators capable of querying global workflow repositories, verifying analytical findings across independent compute clusters, and synthesizing collective biological knowledge. Grounding artificial intelligence in open, verifiable infrastructure ensures that the automated science of the coming decade remains transparent, reproducible, and universally accessible.

## Multi-Agent Analytical Divergence Benchmark
We evaluated analytical divergence across autonomous agents using an RNA-seq study of carbohydrate-mediated enterotoxin repression in *Bacillus cereus* (BioProject PRJEB86181, PMC12804731) [10]. The primary contrast compared two glucose-supplemented replicates (ERR14660412 and ERR14660413) against three baseline tryptic soy broth control replicates (ERR14660420, ERR14660421, and ERR14660422) from nineteen total libraries across five growth conditions.

To quantify planning variation, we evaluated 30 isolated agents across three foundation model families: ten Claude Opus 5.5 agents (Anthropic), ten Codex agents running GPT-6 Astra (OpenAI), and ten Gemini 3.8 Flash agents within Antigravity (`agy`, Google). Each agent received identical natural-language instructions in an empty local workspace directory with no prior session context, external memory, or access to Galaxy cyberinfrastructure (Table [tab:planning_prompt]). We parsed each generated plan across eight sequential analytical decisions: reference genome assembly, workflow engine, read trimming software, ribosomal RNA depletion strategy, read aligner, quantified genomic feature, differential expression model scope (19-sample pooled vs. 5-sample contrast-only), and log-fold-change shrinkage prior. Combinatorial trajectory diagrams were constructed from this discrete decision matrix. Model families exhibited distinct planning profiles. Claude plans aligned to *Bacillus pacificus* anQ-h4 and pooled variance across all nineteen libraries. Codex plans aligned to an alternative reference strain (*Bacillus cereus* ATCC 10987) and restricted the comparison to the five target replicates. Gemini plans showed severe instability across assemblies. They selected an unrelated strain in one plan and repeatedly reversed library strandedness. Aligning against a different bacterial strain alters gene coordinates and annotations. Inverting library strandedness discards or miscounts real transcripts. Pooling all nineteen libraries to estimate variance alters statistical power compared to analyzing only the five target replicates.

## Galaxy-Native Replication of *Bacillus cereus* RNA-seq
To evaluate autonomous replication on public cyberinfrastructure, we connected the Antigravity CLI (`agy`) to UseGalaxy.org through the Galaxy Model Context Protocol server (`galaxy-mcp`) [11]. The five target RNA-seq libraries from BioProject PRJEB86181---two glucose-supplemented replicates (ERR14660412 and ERR14660413) and three tryptic soy broth control replicates (ERR14660420, ERR14660421, and ERR14660422)---were imported into a public Galaxy history (ID `bbd44e69cb8906b59549f5524d3906f3`) alongside the *Bacillus cereus* ATCC 10987 reference genome and RefSeq coding sequence (CDS) transcriptome (4.75 MB, 5,472 unique coding loci, dataset HID 106).

Before launching the full analysis, the agent validated its workflow on a 1,000-read pilot subset. In NCBI RefSeq bacterial CDS FASTA exports, genes containing programmed ribosomal frameshifts or internal stop codons are split across multiple coordinate intervals that share the same locus tag with numerical suffixes (`#1`, `#2`). Because Kallisto index construction rejects duplicate target identifiers, the agent deduplicated these split headers on the pilot subset before processing the full libraries.

The agent assembled and validated a reusable Galaxy workflow (ID `ea7670a8c3fa3562`) combining FastQC, fastp, Kallisto quant [17], DESeq2, and MultiQC. During workflow construction, Galaxy's workflow schema validator enforces strict input-output type compatibility across connected steps. When the agent initially wired Kallisto's output collection of transcript-level abundance tables directly into DESeq2's singular tabular count input, the editor rejected the connection with a type mismatch warning. Inspecting the validation response returned by the MCP server, the agent generated a two-column transcript-to-gene mapping table (`tx2gene.tsv`, dataset HID 148) and configured DESeq2's integrated `tximport` mode to aggregate collection-level transcript abundances into gene-level counts (output collection HID 175, DESeq2 results HID 188). To verify that unspliced pseudoalignment against coding sequences matched whole-genome spliced alignment, we also ran a parallel HISAT2 and featureCounts pipeline against the full 5.43 MB genome assembly. Across all 5,472 bacterial genes, Kallisto pseudoalignment (40 seconds runtime, 12 MB output footprint) and HISAT2 spliced alignment (15 minutes runtime, 5.8 GB coordinate-sorted BAM footprint) produced near-identical $\log_2$ fold-change estimates (Pearson $r = 0.9622$, $R^2 = 0.9258$). All workflows, datasets, and comparison notebooks are archived in Galaxy Page `93fcddc692e0986f` and interactive JupyterLab dataset HID 192.

## Galaxy Model Context Protocol and Modular Skills
Agents interact with computational infrastructure through the Galaxy Model Context Protocol server (`galaxy-mcp`) [11]. The Model Context Protocol establishes an open standard for tool execution and data inspection. Rather than allowing agents to execute arbitrary local shell commands, the server provides forty-four structured endpoints. These endpoints enable agents to search tool registries, inspect dataset collections, launch workflows, and monitor execution states through standard input-output streams or remote HTTP connections. The server is implemented in Python utilizing the official BioBlend library to communicate with the Galaxy REST API. Transport mechanisms include standard input-output (stdio) for local CLI integration and streamable HTTP for web and remote clients. Authentication occurs through long-lived Galaxy API keys or OAuth2 token exchanges. The server provides structured error handling and schema validation across all parameter endpoints.

Domain expertise is provided through modular skill packages [12]. These skills teach language models standard bioinformatics conventions. Skills guide tool discovery, parameter selection, and collection manipulation idioms. For complex multi-step pipelines, Workflow Foundry skills compile validated workflow templates directly into agent memory [9]. By separating operational skills from the underlying compute runtime, the framework ensures that agents execute verified analytical procedures rather than generating unvalidated guesses.

## User-Defined Tool Architecture
User-Defined Tools are written in YAML adhering to the `GalaxyUserTool` class definition. The tool wrapper specifies a mandatory container image hosted on public registries (Quay.io, Docker Hub), typed input parameters, declared output datasets, and an execution command. Commands are templated using sandboxed ECMAScript evaluation executed inside an isolated V8 runtime. Output files are claimed from the working directory through `from_work_dir` designations or dynamic dataset discovery patterns.

## Orbit Workbench and Execution Guard
Orbit is constructed as an Electron desktop application powered by a headless agent runtime built as an extension on Pi.dev. The runtime manages session context, system prompts, and tool registration. The execution guard intercepts tool calls via internal lifecycle hooks, classifying actions across model tiers, path security, and shell hazard. Local file writes are strictly confined to the workspace root using realpath resolution. Remote Galaxy jobs are tracked through YAML invocation blocks embedded within `notebook.md`, which are updated via background polling and asynchronous event handlers.

## Workflow Foundry Casting Pipeline
The Workflow Foundry compiler is implemented in TypeScript and Node.js. Molds are written as Markdown documents carrying structured Zod-validated YAML frontmatter declaring pattern dependencies, manual references, and input-output schemas. The casting pipeline compiles Molds into target-specific agent skills. Synthesized workflows are validated statically using the `gxwf` validation engine, which verifies graph topology, step connectivity, and tool state against official Galaxy XML schemas and IWC exemplars.
